# 🧠 Dyslexia Detection Using AI

An AI-powered web application designed to assist in the **early screening of dyslexia** using interactive assessments, reading performance, and machine learning.

### ✨ Features

* 🎮 Interactive games and reading assessments
* 📊 Performance and reading analysis
* 🤖 CNN and XGBoost-based ML prediction
* 📈 Dyslexia risk assessment
* 👨‍👩‍👧 Parent–student management
* 👨‍💼 Admin dashboard and user management
* 🗄️ PostgreSQL database for storing assessment results

### 🛠️ Tech Stack

**Frontend:** React, TypeScript
**Backend:** Python
**ML:** CNN, XGBoost, Scikit-learn
**Database:** PostgreSQL

### 🔄 Workflow

```text
Interactive Assessment
        ↓
Performance & Reading Data
        ↓
Data Processing
        ↓
CNN + XGBoost
        ↓
Risk Assessment
        ↓
Results & Progress Tracking
```

### ⚠️ Disclaimer

This project is intended for **research and preliminary screening purposes** and does not replace professional diagnosis.
